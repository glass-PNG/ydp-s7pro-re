# 边界与免责声明

## 这是什么

对**我自己购买的**一台有道词典笔 S7 Pro 做的技术研究记录：协议帧、分区表、
OTA 容器、boot 镜像结构，以及大量失败记录。目的是给这台设备做一份完整备份，
并让后来者少踩坑。

## 这不是什么

- 不是破解教程：不涉及绕过付费内容、授权、DRM
- 不是通用工具：所有脚本都针对这一型号的协议，直接套用到别的设备大概率无效
- 不是漏洞利用：文中的「凭据已剔除」是硬要求，公开版本里没有任何可用于
  冒充设备请求厂商服务的密钥

## 公开版本的脱敏清单

发布前已剔除/替换：

| 字段 | 处理 |
|---|---|
| `deviceSecret` / `productSecret` | 删除 |
| `deviceId` / `productId` | 替换为占位符 |
| 设备序列号（`mid` / SN） | 删除 |
| MAC 地址 | 删除 |
| 路由器会话 cookie / csrf token | 删除 |
| 本机内网 IP、主机名、用户名、绝对路径 | 替换为占位符 |
| 抓包文件中的个人数据 | 不发布 |

## 请你遵守

1. **只在你拥有的设备上**做这些实验。
2. 不要用本文的方法去改别人的设备、不要帮人「解锁」二手设备。
3. 不要把 OTA 劫持方法用在生产网络或他人的网络上。
4. 文中标注为「可能变砖」的操作，请先做好你**自己能承受的**最坏打算 ——
   本项目目前**没有**救砖通道。

## 关于保修

改 boot 分区、写非官方镜像，基本一定会影响保修。请自行权衡。
